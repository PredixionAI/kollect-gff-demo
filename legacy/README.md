# Legacy / archived files

Kept for reference only — nothing here is loaded by the running app.

- `build_frontend.js` — the one-shot generator that originally scaffolded
  the 6-screen flow. Superseded once `public/js/dashboard.js` and
  `public/css/styles.css` started being hand-edited outside of it. **Do not
  run this** — see the banner comment at the top of the file.
- `voice-select.js`, `case-study.js` — the 4-screen flow's voice-grid and
  case-study screens, replaced by `orbs.js`/`archetype.js`/`persona.js` when
  the flow expanded to 6 screens. No longer referenced from `index.html`.
- `_extracted_css.txt`, `_extracted_js.txt` — leftover scratch output from
  an earlier pass that split the original monolithic HTML draft apart.
